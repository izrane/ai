FONCTIONNEMENT
──────────────
• Bouton FR/AR (déjà existant) : quand l'utilisateur passe en ARABE,
  chaque définition des dictionnaires s'affiche en ARABE, avec le
  français original en petit dessous entre « … ».
• Mode FR : rien ne change, tout reste en français.
• Hors-ligne : glossaire intégré (~1 000 mots + expressions + codes
  grammaticaux) → environ 60 % du vocabulaire courant couvert.
• En ligne : si une définition est mal couverte par le glossaire,
  l'API MyMemory (fr→ar) la traduit puis le résultat est mis en cache
  dans localStorage (izran-fr-ar-cache-v1) — les requêtes suivantes
  sont instantanées et gratuites.
• Les mots tamazight en latin et le tifinagh ne sont jamais touchés :
  ils restent tels quels dans la traduction (c'est le comportement voulu,
  ce sont les mots de la langue source).
• Dégradation gracieuse : si i18n-ar.js est absent, la page fonctionne
  exactement comme avant (helpers avec repli).

PRONONCIATION ARABE (TTS)
──────────────────────────
• Technologie : Web Speech API du navigateur (speechSynthesis) —
  aucune clé, aucun serveur : fonctionne hors-ligne dès qu'une voix
  arabe est installée sur l'appareil.
• Où : petit bouton rond (haut-parleur) à côté de chaque définition
  arabe — suggestions, favoris, lexique, OCR, réponses du chat.
  Un clic = lecture ; re-clic sur le même bouton = arrêt.
• Choix de la voix si plusieurs : ar-MA (Maroc) > ar-DZ > ar-SA >
  ar-EG > ar-TN > ar-LY > voix locale > première voix arabe.
• Texte mixte : seuls les passages en écriture arabe partent sur la
  voix arabe ; les mots latins restent sur la voix française.
• Bouton « Écouter » du chat : lit maintenant aussi l'arabe avec la
  voix arabe (avant : tout passait sur la voix française).
• Si aucune voix arabe n'est installée : petit toast d'aide bilingue
  (FR/AR) — rien ne casse. Pour en ajouter une :
  – Android : Paramètres → Langue et saisie → Synthèse vocale →
    télécharger l'arabe
  – Windows : Paramètres → Heure et langue → Voix → Ajouter des
    voix → Arabe
  – iOS/macOS : Réglages → Accessibilité → Contenu énoncé → Voix
    → Arabe (Maged/Majed)
  Puis recharger la page.

MÉTHODE RAPIDE POUR TESTER
──────────────────────────
Ouvrez la page, cliquez le bouton 🇫🇷/FR (coin haut), il devient AR :
tapez « soleil » → la réponse affiche l'arabe + le français, et un
petit bouton haut-parleur apparaît à côté de chaque mot arabe →
cliquez dessus : le mot est prononcé en arabe.
Ouvrez le panneau Favoris & Lexique 📚 → définitions bilingues +
boutons de prononciation. Le bouton « Écouter » du chat lit le
message entier en respectant chaque écriture (tifinagh/arabe/français).

SAISIE ARABE → TAMAZIGHT (les deux sens)
─────────────────────────────────────────
Dans le champ de saisie (chat ouvert), tapez en ARABE : « شمس » →
suggestions instantanées du mot rif correspondant ; Envoyer →
réponse : « شمس → tfuët (ⵜⴼⵓëⵜ) · 🟢 Rif ».
Essayez aussi « الشمس » (avec article), « الخبز والملح » (deux mots),
ou un mot absent du glossaire (ex. « مدرسة ») : la traduction passe
par l'API en ligne (nécessite une connexion).
Sens inverse : tapez « tfuët » ou « ⵜⴼⵓëⵜ » → la définition
s'affiche en arabe (mode AR) avec prononciation.
Mots-clés arabes du chat : « مرحبا » (salutation), « المفضلة »
(favoris), « قاموس » (lexique).

NOTES TECHNIQUES
────────────────
• Aucun dico*.js n'a été modifié : la traduction se fait à l'affichage.
• API MyMemory : gratuite, sans clé, limite ~500 caractères/requête
  (le moteur tronque à 480) — usage occasionnel uniquement pour les
  définitions mal couvertes.
• Pour personnaliser le glossaire : éditez l'objet WORDS au début de
  i18n-ar.js (clé = mot français minuscule, valeur = arabe).
• Pour ajuster la vitesse de lecture arabe : dans tts-ar.js,
  cherchez « u.rate = 0.9 » (0.8 = plus lent, 1.0 = normal).
• Le cache des traductions API peut être vidé via la console :
  localStorage.removeItem('izran-fr-ar-cache-v1')   (FR → AR)
  localStorage.removeItem('izran-ar-fr-cache-v1')   (AR → FR, saisie)
• Si ar-input.js est absent : la saisie arabe est ignorée (la page
  fonctionne exactement comme avant).
• Si tts-ar.js est absent : la page fonctionne comme avant, sans boutons
  de prononciation (les définitions bilingues restent intactes).
